處理流程

上傳後會發生什麼？

  1. 檔案上傳到租戶獨立的儲存空間（GCS）
  2. 進入 RAG pipeline：文件解析 → 欄位抽取 → Chunk 分組
  3. 產出 Mirror View 預覽，可審視模型抽取是否正確
  4. 管理員「確認」後，Chunks 才進入向量庫，可被 Chat 引用
